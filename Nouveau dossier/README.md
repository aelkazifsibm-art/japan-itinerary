\# Japon Route App 🇯🇵



Application qui transforme une intention humaine floue

en itinéraire réel au Japon (marche + train).



\## Fonctionnement

1\. Intention floue → IA

2\. Lieu réel → Google Places

3\. Trajet réel → Google Directions (TRANSIT)

4\. Affichage minimal



\## Stack

\- Vercel (serverless)

\- Node.js

\- OpenAI API

\- Google Maps Platform (Places + Directions)



\## Installation

npm install

vercel dev



\## Variables d’environnement

Voir `.env.example`
